Going live with real money

1. On Kalshi (production) create an API key and fund the account.
2. Here choose Live, type the phrase, paste the production key ID and private key, then Save. Your demo key stays saved separately.
3. Press Run readiness check — every line should say OK.
4. Press Start. The limits on the right are percentages of the account, so a $100 account risks only a few dollars per contract.
5. Keep this PC awake and online. Kill cancels everything and blocks trading at any time.
